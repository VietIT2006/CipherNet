# UI-03 — Xử lý gửi gói DATA & nhận kết quả trên Client

- **Mã Task:** `UI-03`
- **Sprint:** 3
- **Độ ưu tiên:** Cao
- **Story Points (SP):** 3 SP

---

## 1. Mục tiêu (Goal / User Story)
Lập trình sự kiện gửi gói tin UDP DATA và tiếp nhận phản hồi từ Server.

## 2. File liên quan (Affected Files)
- `app/src/main/java/com/detai10/client/ClientApp.java`

## 3. Yêu cầu kỹ thuật chi tiết (Technical Requirements)
Kiểm tra hợp lệ dữ liệu (không để trống tên file/nội dung); đóng gói DATA|mode|fileName|content; gửi qua UDP; nhận và hiển thị danh sách index HELLO lên giao diện.

## 4. Tiêu chí hoàn thành (Definition of Done)
- [ ] Dữ liệu gửi đi và hiển thị kết quả phản hồi chuẩn xác.
- [ ] Đảm bảo code sạch, có comment giải thích rõ ràng và tuân thủ quy chuẩn dự án.
